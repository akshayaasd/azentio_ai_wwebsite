# Azentio Visual Identity & Design System Guidelines

1. **Color Palette**:
   - Background: Dark Navy `#070D1E` / Deep Slate `#0B132B`
   - Primary Accent: Azentio Blue `#0066FF` / Electric Cyan `#00A3FF` / `#00D2FF`
   - Success / Compliance: Emerald `#10B981`
   - Warning / Moderation: Amber `#F59E0B`
   - Security / Boundary Breach: Rose `#F43F5E`

2. **Typography**:
   - Modern enterprise geometric sans (`Plus Jakarta Sans` or `Inter`).
   - Monospace font for IDs, keys, audit hashes, and code blocks (`JetBrains Mono` or `system monospace`).

3. **User Experience**:
   - Evaluator Role Switcher must be prominently visible at the top of every screen.
   - Micro-interactions, subtle borders (`rgba(30, 47, 86, 0.7)`), and glassmorphism panels.
